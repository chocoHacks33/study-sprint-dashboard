# Study Sprint Dashboard

A small, dependency-free dashboard for reviewing recent study sessions. It summarizes focused time, active courses, average session length, and the daily study pattern from realistic seed data.

## Run locally

```sh
python -m http.server 8000
```

Open <http://localhost:8000> in a browser.

## Verify

```sh
npm test
npm run check
```

The app uses plain HTML, CSS, and JavaScript modules, so there is no build step or runtime dependency.
